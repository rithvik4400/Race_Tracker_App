# 🏃‍♂️ Race Tracker Game

A fun and interactive **Android mini-game** built using **Kotlin + Jetpack Compose**, where players compete in a race by tapping to run!

---

## 🎮 Features

* 🏁 **Tap-to-Run Gameplay** – Tap fast to move your runner
* 🤖 **AI Opponent** – Compete against an auto-moving player
* 📊 **Live Progress Tracking** – Real-time race progress bars
* 🏆 **Winner System** – First to reach 100% wins
* 💰 **Coin Rewards** – Earn 100 coins on winning
* 🎯 **Player Selection Screen**
* 🚀 **Smooth Navigation (Compose Navigation)**
* 🔁 **Reset & Replay Option**
* ✨ **Modern UI with animations**

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/rithvik4400/race-tracker.git
   ```

2. Open in **Android Studio**

3. Sync Gradle

4. Run the app on emulator or device 📱
